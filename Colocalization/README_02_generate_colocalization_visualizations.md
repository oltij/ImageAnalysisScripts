## 8.1 Purpose

This is the visualization/QC-only stage.

It reads the single HDF5 analysis file generated by:

```text
01_run_colocalization.py
```

It does **not** recalculate the stable matching.

This allows display and QC settings to be changed freely without rerunning the colocalization analysis.

# 15. Final unmatched-object QC outputs

The script creates:

```text
visualizations/unmatched_only_qc/
```

It defines:

```text
A-only = an Object-A ROI not retained in the final one-to-one matching
B-only = an Object-B ROI not retained in the final one-to-one matching
```

This does **not** necessarily mean zero spatial overlap.

An unmatched object may:

1. have no overlap;
2. have only sub-threshold overlap; or
3. have an eligible partner but lose the final one-to-one matching competition.

# 17. Unmatched-object intensity metric fields

Raw intensity statistics are calculated from the original fluorescence arrays stored inside the HDF5 file.

For every sampled image/ROI combination, the script creates:

```text
<prefix>_Mean
<prefix>_Median
<prefix>_Std
<prefix>_Min
<prefix>_P05
<prefix>_P95
<prefix>_Max
```

Statistics are calculated for combinations including:

```text
Object-A channel inside Object-A ROI
Object-B channel inside Object-A ROI
Object-A channel inside Object-B ROI
Object-B channel inside Object-B ROI
Object-A channel inside true mask intersection
Object-B channel inside true mask intersection
```

For the current LHX6/PV run, example field names therefore look like:

```text
LHX6_Channel_In_LHX6_ROI_Mean
LHX6_Channel_In_LHX6_ROI_Median
PV_Channel_In_LHX6_ROI_Mean
PV_Channel_In_LHX6_ROI_P95
LHX6_Channel_In_PV_ROI_Mean
PV_Channel_In_PV_ROI_Max
LHX6_Channel_In_Intersection_Mean
PV_Channel_In_Intersection_Median
```

These are raw image-intensity values, not the display-normalized intensities used in PDF rendering.

# Important input-file note

The HDF5 input is intended to be self-contained: it stores the original fluorescence arrays, ROI pixel tables, matching tables, metadata, and filtering-stage tables needed by this visualization script.

## 26.6 HDF5 is intended to be self-contained

Once `01_run_colocalization.py` has produced its HDF5 result, the visualization stage uses:

```text
embedded original fluorescence images
embedded pixel tables
embedded matching tables
embedded metadata
```

rather than reopening the original CSV/TIFF inputs.

This makes the HDF5 file the analysis record that should be archived with the run.
